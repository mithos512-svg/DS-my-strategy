# FPF-семинары - индекс расшифровок

Расшифровки слайдов семинаров практикума FPF (Анатолий Левенчук), конвертированы
из Keynote (.key) в текст для личного пака.

## Семинар 2 (19.07.2026)

«Какие ходы решают судьбу проекта: архитектурное мышление, когда системного уже мало»

169 слайдов, разбито на 6 частей:

- [Часть 1/6](FPF-seminar-2-part1.md) - слайды 1-33: выбор системы, границы, ход «сначала вверх, затем внутрь», холон
- [Часть 2/6](FPF-seminar-2-part2.md) - слайды 34-61: проект как составная работа, build-the-builder, структуры потока преобразований
- [Часть 3/6](FPF-seminar-2-part3.md) - слайды 62-87: сети структур потока, системная мантра, характеристики и шкалы
- [Часть 4/6](FPF-seminar-2-part4.md) - слайды 88-117: сравнение вариантов, модульность, размещение, контуры управления, этическая медиация
- [Часть 5/6](FPF-seminar-2-part5.md) - слайды 118-143: архитектура метода/работы/эпистемы/дисциплины, изобретательский поиск, ADR
- [Часть 6/6](FPF-seminar-2-part6.md) - слайды 144-169 (финал): описания и публикация, эпиплексия, повторная сборка P2S, итоговая практика

**Источник:** `FPF_second_seminar_slidement_19jul26.key` (Keynote, 320МБ).

**Примечание про нумерацию:** запрошено пользователем как «ФПФ-3», но по содержанию файла
это семинар **2** серии (заголовок «...когда системного уже мало», плюс явная фраза
внутри «На третьем семинаре этот вход разворачивается в P2W»). Пользователь подтвердил
02.08.2026, что планирует загрузить все 5 семинаров серии по очереди - расхождение
в номере не ошибка, а факт того, что этот файл просто оказался семинаром 2.
