## R4.3:3 / R4.3:Tasks2 - ищем причины и следствия

Текст уроков - MimEcoSys/docs, commit faed795. Модель (EN): `current/projects/Ataccama-DataTrust/cause-effect-pairs-case-queue-r4.md` (v1.0); пост (RU): `current/posts/2026-11-26-r4-3-tasks2-causes-effects.md`. Сверка: FPF C.28.CM:4, C.28:4.1, Library.Reference:6.5.3.2.

- 17 пар «причина - следствие» (8 из гипотез, 9 дополнительных), у каждой тип: необходимая / достаточная / способствующая.
- Достаточная сама по себе только одна - бухгалтерское тождество (поступление > закрытия → очередь растёт). Остальные «достаточные» - сочетания условий, или по правилу, или только для показателя.
- Тип причины зависит от правил: «срочное → всё встало» достаточна только по правилу «срочное вытесняет всё».
- Найдена петля: ожидание → эскалация → срочное → простой → меньше закрытий → ожидание; разворачивается во времени.
- Три разных вопроса: почему очередь появилась / почему держится / что сократит.
- Контрфактика: мир с резервом 20 % для запросов руководства; кейс GTIN в мире с разбором и лимитом с апреля.
- Ловушка отбора: срок по закрытым кейсам занижен.
