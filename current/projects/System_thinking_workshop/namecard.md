# NameCard: «Книжный клуб» → Systems Thinking Workshop

## Именуемое значение

Повторяющаяся сессия с командой: один реальный рабочий кейс разбирается через
один паттерн FPF, чтобы со временем нарастить системное мышление команды.
**Цель — системное мышление команды.** Формат (клуб/воркшоп/что угодно) —
вопрос второго порядка, отдельный от цели.

## Тип и предметный паттерн

Повторяющаяся групповая практика (не единичное событие), результат которой —
развитие мышления участников, а не производство конкретного рабочего продукта
на каждой сессии.

## Почему прежнее имя не подошло

«Книжный клуб» / «Book Club» — прямая ложная ассоциация: подразумевает
совместное чтение книги по главам. На деле книга не читается совместно —
берётся один кейс, разбирается один паттерн. Риск: участники приходят с
неверными ожиданиями (ждут обсуждения прочитанного).

## Рассмотренные кандидаты

| Кандидат | Итог |
|---|---|
| Systems Clinic | Отклонён — метафора «клиники» непрозрачна без знакомства с форматом office hours |
| Systems Practice | Отклонён — риск спутать с «best practices» |
| Pattern Lab | Отклонён — звучит технично, может отпугнуть нетехническую часть команды |
| Case Workshop | Отклонён — понятен формат, но не видна цель |
| **Systems Thinking Session / Workshop** | **Выбрано** — прямо называет цель, не требует расшифровки метафоры |

## Решение

- **TechLabel** (документы, планы): *Applied Systems Thinking Session*
- **PlainLabel** (приглашение команде, разговор): **Systems Thinking Workshop**

## Где имя действует

- Приглашения участникам, разговор с командой — PlainLabel
- current/WeekPlan, current/Strategy-*, current/PriorityProjects-* — TechLabel
  или PlainLabel по контексту
- Все рабочие материалы проекта собраны в
  `current/projects/System_thinking_workshop/` (перенесено 09.08)
- Архивные записи (archive/day-plans/, archive/WeekPlan) с прежним именем
  «книжный клуб» — **не переписываются**, это исторический протокол принятия
  решений на момент, когда старое имя ещё использовалось

## Условие пересмотра

Пересмотреть, если после 2-3 реальных сессий с командой название всё ещё
вызывает вопросы «а что это вообще такое» при приглашении — тогда вернуться на
шаг 4 мантры F.18 с новыми кандидатами, с учётом реальной реакции команды.
