## Модель capability instance (A.2.2, 6/6 полей закрыто)

| Поле | Значение |
|---|---|
| **holder** | 3 независимых экземпляра - каждый из 3 сотрудников отдельно |
| **canDo** | Самостоятельно (консультация с ИИ в процессе разрешена) распознать применимое базовое понятие/паттерн системного мышления в реальной рабочей ситуации в рамках своей роли и довести это до практического результата |
| **envelope** | Ситуации - любые реальные рабочие ситуации в рамках роли сотрудника; паттерны - растущий список, сейчас пустой (ни одного занятия не было), пополняется по мере занятий; инструменты - fpf.sh + консультация с ИИ разрешены, но само распознавание - за человеком |
| **measures** | Качественно: реальный кейс, принесённый на занятие, с показанным распознаванием + применением |
| **qualificationWindow** | 3 месяца без применения на реальном кейсе → способность считается "устаревшей", нужно освежить |
| **currentnessCondition** | Доступ к fpf.sh + доступ к ИИ-консультации должен сохраняться |

**Статус: 6/6 полей закрыто.** Модель способности готова. Envelope сейчас
пуст - ни одно занятие ещё не проведено, ни один паттерн ещё не пройден.
