## Тема сессии 2 (черновой выбор)

**Кандидат: F.9 «Alignment and Bridge across Contexts»** - уже частично
затронут как опциональный блок в сессии 1 (пример с разным пониманием
«готово» между командами). Логичное продолжение: от «конфликт метрики
внутри одной системы» (B.2, сессия 1) к «мосты между разными смысловыми
контекстами разных команд» (F.9, сессия 2) - естественное развитие темы,
а не случайный скачок.

**Кейс-кандидат:** тот самый пример из опционального блока сессии 1 -
слово «готово» означает разное для ремонтной бригады и для команды,
принимающей работу. Хороший кандидат: конкретный, уже возникал в разговоре,
не придуман с нуля.

## Черновая структура (по аналогии с сессией 1)

1. Разогрев (5-10 мин) - напомнить итог сессии 1, связать с темой сегодня
2. Блок с кейсом (15-20 мин) - разбор примера «готово» через призму F.9
3. Применение к реальному кейсу команды (15-20 мин) - если есть текущий
   похожий конфликт понятий между командами - взять его
4. Итог сессии - чек-лист/принцип, который можно унести с собой
