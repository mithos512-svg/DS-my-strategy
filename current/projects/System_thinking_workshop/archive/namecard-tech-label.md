# NameCard: TechLabel — Applied Systems Thinking Session

## Именуемое значение

То же именуемое значение, что и в основной карточке (namecard.md): повторяющаяся
сессия, где команда разбирает один реальный рабочий кейс через один паттерн
FPF, чтобы со временем нарастить системное мышление команды.

Эта карточка — отдельный проход мантры F.18 именно для **технического имени**
(TechLabel), а не для разговорного (PlainLabel = Systems Thinking Workshop,
уже выбран). В первом проходе TechLabel был назначен быстро, без полного
сравнения кандидатов — здесь это исправлено.

## Тип и предметный паттерн

Формальное имя для контекстов, где точность важнее лёгкости восприятия:
плановые документы (WeekPlan, Strategy), протоколы, календарные приглашения
с описанием для руководства, отчётность о развитии команды.

## Нужен ли устойчивый термин отдельно от PlainLabel?

Да. PlainLabel «Systems Thinking Workshop» ориентирован на команду-участника —
понятен с первого взгляда, но не указывает на **метод** (разбор кейса через
паттерн) и на то, что это часть более широкой инициативы по развитию мышления,
а не разовое мероприятие. Для документов, где решение о повторяемости и
методе имеет значение (например, отчёт руководству о развитии команды),
нужна более точная формулировка.

## Локальный смысл

Кто читает: сам пользователь (в документах планирования), возможно —
руководство при отчёте об инициативах развития команды.
Для какой работы: сослаться на сессию в плане/отчёте так, чтобы было понятно
без пояснений, что это регулярная практика с методом, а не встреча.

## Кандидаты

| Кандидат | Точность | Риск |
|---|---|---|
| **Applied Systems Thinking Session** | Высокая — «applied» отделяет от теоретического обучения, «systems thinking» называет дисциплину, «session» — формат | Длинновато для частого упоминания в таблицах |
| Systems Thinking Practice Session | Высокая, но «practice» может читаться двояко (тренировка vs. устоявшийся метод) | Средний — «practice» уже используется в этой системе для other значений (time-investment practice) |
| Case-Based Systems Thinking Session | Точно называет метод (через кейс), но не называет цель | Средний — фокус смещается на механизм, не на результат |
| Systems Pattern Application Session | Технически точно (паттерн + применение), но требует знания термина «паттерн» | Высокий для нетехнического читателя документа |

## Сравнение

«Applied Systems Thinking Session» точнее остальных передаёт связку
цель+формат (в отличие от Case-Based.../Pattern... кандидатов, которые называют
только механизм). «Practice Session» создаёт риск путаницы с уже
существующим в репозитории термином «инвестирование времени / практика»
(time-investment-log). Длина приемлема для документов (не для устной речи —
там и так используется PlainLabel).

## Решение

**TechLabel подтверждён:** *Applied Systems Thinking Session*

Используется в: current/WeekPlan, current/Strategy-*, current/PriorityProjects-*,
любых формальных отчётах об инициативе. PlainLabel (Systems Thinking Workshop)
остаётся для разговора с командой и приглашений — см. namecard.md.

## Условие пересмотра

Пересмотреть, если TechLabel окажется неудобным при частом упоминании в
таблицах (слишком длинный) — тогда рассмотреть сокращение до аббревиатуры
(например, «AST Session») с расшифровкой при первом упоминании в документе.
