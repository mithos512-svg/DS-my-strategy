### Слайд 2. С какой задачей вошёл и что получил

**Задача на входе:** учёба по двум курсам шла, но заметки разрозненны, планы
терялись между неделями, учёт здоровья (вес/питание/сон) жил в голове,
договорённости с самим собой забывались.

**Результат через 5 недель:** работающая система день→неделя→месяц: каждый день
открывается и закрывается ритуалом, всё пишется в GitHub-репозиторий, Claude
ведёт ритуалы сам — мне остаётся диктовать.

### Слайд 3. Как это устроено (без техники, одна картинка)

GitHub-репозиторий из трёх папок:
- **current/** — живые документы: план дня, план недели, дневники (питание, вес, сон, время, учёба)
- **memory/** — README (точка входа для нового чата) + файл правил
- **archive/** — закрытые дни и недели

Новый чат с Claude начинается с чтения README — и система «вспоминает» всё:
контекст, правила, текущий статус. Это и есть экзо-память.

---

### Слайд 4. Что использую каждый день

- **Day Open:** вес, завтрак, план дня из плана недели — 2 минуты голосом
- **Питание:** фото тарелки или голосом «завтрак стандартный» — Claude считает
  ккал/белок/клетчатку по моим шаблонам
- **Время:** «закрывай помидорку S1» — записано
- **Day Close:** итоги, неудовлетворённости дня, сон (score из Apple Health),
  обновление статуса — Claude проводит по чек-листу сам

### Слайд 5. Развитие: учёба со сверкой по первоисточнику

Главное правило системы: обратная связь по курсам — только со сверкой через
первоисточник, не «по памяти ИИ».

Работает так: я диктую понятие/ответ своими словами → Claude находит раздел
курса → показывает, где я совпал, а где источник говорит другое.

За 5 недель: 14 понятий «Стратегирования» проработаны полностью, 10 вопросов
главы «Личность и агент» — расхождения оказались ценнее совпадений.

### Слайд 6. Планирование: от дня к месяцу

- Недельные сессии стратегирования (по методике курса, PD.METHOD.008)
- Первая месячная Strategy Session: неудовлетворённости → гипотезы → приоритетные
  проекты → недельный план
- «Стоп-лист хвостов»: задача, перенесённая 3 раза — требует явного решения
  (закрыть/отбросить/переназначить), четвёртый молчаливый перенос запрещён
- Побочный эффект: планирование реально заменяет медитацию (проверил на себе)

### Слайд 8. Что стало проще (цифры за 5 недель)

- Вес: −2.5 кг (86.7 → 84.2 средненедельный), % жира 20.8 → 18.8
- Учёба: 14+10 понятий/вопросов со сверкой, 2 поста опубликованы в клубе
- Время: учитывается каждый день, «помидорка» = одна голосовая фраза
- Хвосты: не копятся — стоп-лист решает за один Day Close
- Новый чат = продолжение старого, а не начало с нуля

### Слайд 9. Где было сложно (честно)

- Приучить себя к ритуалам Day Open/Close — первые дни забывал
- Инструменты платформы иногда сбоят — решение: правило «Claude обязан явно
  сказать о сбое, а не молча продолжить» (теперь это правило №15)
- Файлы дублировались между current/ и archive/ — решение: правило
  «архивация = перенос, не копирование»
- Вывод: система выросла из ошибок — каждый сбой становился новым правилом

дальше система начнёт расти сама из ваших потребностей.
